Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 24 November 2026

Ekstensi Chrome e-BMD Auto-Pilot Pro dikembangkan sebagai alat produktivitas untuk membantu instansi Pemerintah Daerah dalam mengotomatisasi pengunduhan laporan aset dan penyusunan Master Excel pada portal SIPD e-BMD.

1. Pemrosesan Data 100% Lokal (Client-Side)

Seluruh proses pengunduhan laporan KIB, pembacaan struktur Excel (melalui pustaka lokal SheetJS yang dibundel di dalam ekstensi), serta penyimpanan file ke folder komputer pengguna berjalan 100% secara lokal di dalam sesi browser pengguna.

2. Data yang Tidak Kami Kumpulkan

  • Kami tidak mengumpulkan, mengirimkan, atau menyimpan data aset BMD/SKPD ke server eksternal mana pun.
  • Kami tidak mengumpulkan username, kata sandi, cookie sesi, maupun kredensial login portal e-BMD Anda.
  • Kami tidak melacak riwayat penelusuran internet (browsing history) atau data pribadi (PII) pengguna.
  • Kami tidak menjual atau membagikan data pengguna kepada pihak ketiga maupun jaringan periklanan.

3. Penyimpanan Lokal Browser

Ekstensi hanya menggunakan API chrome.storage.local di perangkat pengguna untuk menyimpan:

  • Kode lisensi aktivasi daerah (jika diaktifkan oleh pengguna).
  • Alamat URL halaman parameter laporan e-BMD terakhir untuk kemudahan navigasi tombol cepat.

4. Izin Ekstensi (Permissions)

  • storage: Menyimpan kode lisensi dan preferensi lokal di browser pengguna.
  • activeTab: Membaca hostname tab aktif hanya ketika pengguna mengklik ikon ekstensi untuk memverifikasi kecocokan domain lisensi.
  • Akses halaman laporan (*://*/*dbpb_param.aspx* & *://*.mubakab.go.id/*): Menyuntikkan tombol kontroler ekspor pada halaman parameter laporan e-BMD.

5. Kontak Dukungan

Jika Anda memiliki pertanyaan terkait kebijakan privasi ini, silakan hubungi tim pengembang melalui WhatsApp resmi 0882-7119-5803 atau melalui kontak dukungan yang tertera pada halaman listing Chrome Web Store.
